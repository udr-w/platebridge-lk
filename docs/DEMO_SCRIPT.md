# 7–10 minute demonstration script

Before presenting, run `./scripts/reset-demo.sh` (Windows: `scripts\reset-demo.cmd`) and open the landing page.

## 0:00–1:00 — Problem and proposal

“Suitable food can become waste because its safe handover window is short and coordination is fragmented. PlateBridge LK is not a random leftovers marketplace. It is a safety-screened, dignified local coordination network.” Point to the three principles and recommended limited Galle pilot.

## 1:00–1:40 — Language, dignity and privacy

Switch the header through English → සිංහල → தமிழ் → English. Scroll to privacy. Explain aliases, approximate areas and shared collection points; no one publicly proves need.

## 1:40–3:10 — Household donation and safety

Demo login → `donor.home@platebridge.demo` / `demo123` → **Donate food**. Create “Presentation rice and curry”, six portions, cooked meal, refrigerated, coconut allergen, Galle Fort, deadline in three hours. Continue through the five sections and run the safety check. Show amber: prepared household food and cold-chain handling require review.

Briefly mention the unsafe path: check “previously served” or “partially eaten” in a separate listing to produce red, rejection and future waste-route guidance.

## 3:10–4:00 — Coordinator review

Sign out → `coordinator@platebridge.demo` → **Safety reviews** → open the new listing → review explanation and handling details → **Approve listing**. Explain that amber never publishes automatically.

## 4:00–5:15 — Recipient claim and anonymous mode

Sign out → `recipient@platebridge.demo` → **Privacy**. Show alias “Maya G.” and protected contact/location preview. Open **Nearby food**, filter if desired, select the approved listing → choose portions and self-collection → **Claim food**. Show pickup code and participant masking.

## 5:15–6:40 — Volunteer delivery

Use an available bakery listing and claim with **Volunteer delivery**. Sign out → `volunteer@platebridge.demo` → **Delivery tasks** → accept → open rescue → mark collected with the code → mark delivered. Sign back in as recipient → open rescue → confirm receipt. Show completed rescue and dashboard metrics.

## 6:40–7:30 — Incidents and auditability

From a rescue, choose **Report a problem**, select packaging damage, add a concise description and submit. Sign in as coordinator → **Incidents** → show severity/status and resolve it. Point out the rescue flag, state timeline and no phone-number exchange.

## 7:30–8:30 — Administrator and close

Sign in as `admin@platebridge.demo` → **Administration**. Show fictional users, suspension controls, central safety-rule values and deterministic reset. Close with the limitation: “This is a working coordination prototype, not safety certification or production infrastructure. A pilot needs professional rules, legal/privacy approval, native-language review and accountable local partners.”
