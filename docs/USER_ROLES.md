# User roles

| Role | Demonstrated capabilities |
|---|---|
| Household donor | Dashboard, structured donation, safety result, listing/rescue history, code-confirmed collection |
| Organisation donor | Same donor flow with fictional organisation identity and contribution metrics |
| Recipient | Nearby food, filters, claims, collection/delivery, alias privacy, pickup code, receipt, incidents |
| Volunteer | Available deliveries, handling guidance, accept, collect and deliver |
| Coordinator | Regional amber review, rescues, incident queue and collection points |
| Administrator | Platform metrics, users, suspension, incidents, configurable rule display and demo reset |

Role checks exist in the API, not only in navigation. Demo administrators may see fictional account identity for moderation. Other users see a recipient alias where anonymous mode is enabled.
