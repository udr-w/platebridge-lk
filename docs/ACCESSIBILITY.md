# Accessibility

The prototype uses semantic headings, labels, tables and navigation; keyboard-operable controls; visible focus outlines; sufficient contrast; status text/icons in addition to colour; associated field labels; live loading/toast status; reduced-motion support; and a document language matching the selected locale. Mobile targets are sized for touch.

Before a pilot: perform WCAG 2.2 AA audit with automated and manual tools; test NVDA, VoiceOver and TalkBack; include keyboard-only and low-vision participants; verify Sinhala/Tamil font rendering on common devices; review focus after async navigation and modal confirmation; and publish an accessibility feedback route.
